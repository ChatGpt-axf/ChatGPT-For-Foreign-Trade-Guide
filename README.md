## 一、用 ChatGPT 写英文开发信

开发信是外贸业务中常见的工作内容。

很多新手写出来的邮件有两个问题：一是内容太长，客户没有耐心阅读；二是通篇都在介绍自己，却没有说明产品能给客户带来什么价值。

可以先把产品信息整理清楚，再让 ChatGPT 帮助起草。

例如，你是一家生产不锈钢厨房水槽及配件的工厂，希望联系海外进口商。

可以使用下面这段提示词：

```text
你是一名熟悉厨房卫浴行业的外贸业务员。

请根据以下信息，写一封英文开发信。

产品：SUS304 stainless steel kitchen sinks
身份：中国制造工厂
目标客户：厨房用品进口商、批发商、品牌商
核心优势：支持产品定制、可沟通 OEM 需求

要求：
1. 邮件控制在 120 个英文单词以内。
2. 语言自然，不要使用夸张的营销表达。
3. 突出产品和合作价值。
4. 结尾用一个简单的问题引导客户回复。
5. 不要编造认证、客户案例或工厂产能。
```

生成以后，不要直接给所有客户发送完全相同的邮件。

建议根据客户的网站、产品类型和采购需求调整内容，让开发信更有针对性。

## 二、用 ChatGPT 优化英文产品标题

如果你在 Alibaba.com、独立站或其他跨境平台销售产品，产品标题会影响买家能否快速理解商品。

例如，原始标题可能只有：

```text
Stainless Steel Kitchen Sink
```

这个标题比较宽泛，没有说明材质、产品类型或具体应用。

可以让 ChatGPT 根据真实产品参数生成多个标题版本：

```text
请为一款不锈钢厨房水槽生成 10 个英文产品标题。

已知信息：
材质：SUS304 stainless steel
产品：Kitchen sink
销售对象：海外批发商和进口商

要求：
1. 语言符合自然的英文商品表达。
2. 根据不同关键词组合生成标题。
3. 不要重复堆砌关键词。
4. 不要编造尺寸、认证或功能。
5. 每个标题附上中文解释。
```

生成结果后，再根据平台标题长度限制、实际产品规格和目标市场进行筛选。

需要注意，ChatGPT 可以帮助优化标题，但不能保证某个标题一定获得更高排名或带来更多订单。

## 三、用 ChatGPT 翻译客户邮件

外贸业务员每天可能收到询价、报价确认、交期询问、质量反馈等不同类型的邮件。

直接逐字翻译，往往会让表达显得生硬。

可以使用下面的提示词：

```text
请将下面这段中文翻译成自然、专业的英文商务邮件。

要求：
1. 语气礼貌，但不要过度客套。
2. 符合日常国际贸易沟通习惯。
3. 不改变原文中的价格、数量和交期。
4. 不添加原文没有承诺的内容。
5. 同时提供一个更简短、适合 WhatsApp 的版本。

中文内容：
[在这里粘贴需要翻译的内容]
```

这种方式特别适合报价确认、样品安排、交期沟通和售后协商。

如果涉及合同、索赔或重大价格承诺，仍然应该人工复核，避免翻译造成歧义。
